# MyProject

Проект для обработки банковских операций.

## Возможности

- Маскирование номеров карт и счетов.
- Чтение транзакций из JSON-файлов.
- Чтение транзакций из CSV-файлов.
- Чтение транзакций из XLSX-файлов.
- Фильтрация операций по статусу.
- Фильтрация операций в рублях.
- Сортировка операций по дате.
- Поиск операций по описанию с использованием регулярных выражений.
- Подсчёт количества операций по категориям с помощью `Counter`.
- Интерактивный пользовательский интерфейс.

## Установка

```bash
poetry install
```

## Запуск приложения

```bash
poetry run python -m my_project.main
```

## Тестирование

```bash
poetry run pytest
```

## Проверка типизации

```bash
poetry run mypy src
```

## Проверка форматирования

```bash
poetry run black src tests
poetry run isort src tests
```

## Проверка Flake8

```bash
poetry run flake8 src tests
```

## Покрытие тестами

```bash
poetry run pytest --cov=src --cov-report=term-missing
```
