# MyProject

Проект для обработки финансовых операций.

## Возможности
- Маскирование номеров карт и счетов.
- Чтение транзакций из JSON-файлов.
- Чтение транзакций из CSV-файлов.
- Чтение транзакций из XLSX-файлов.

## Установка
```bash
poetry install
```

## Тестирование
```bash
pytest
```

## Покрытие тестами
```bash
pytest --cov=src --cov-report=html
```
